# Second Look palette — October 24

Owner direction: use the soft monochrome direction from [justus-lumin/x1-design](https://github.com/justus-lumin/x1-design/blob/0f9923b60084f6d5e515d6f79754b1c6e31c98e1/src/app/globals.css), with a hot green/yellow accent requested by Mat. This supersedes waiting for Ryan's design as a prerequisite for changing colors. The app's layout, typography and functional flows are preserved.

| Before | After | Why |
| --- | --- | --- |
| Beige page and navy text | Near-black `#0c0c0c`, charcoal `#121212`, light ink `#ededed` | Adopt the reference's neutral dark direction |
| Rust buttons and active steps | Acid lime `#d9ff43` with near-black button text | Make the next action distinct; retain strong contrast |
| Blue gradients and warm tinted panels | Charcoal depth and neutral status panels | Keep figures and financial states calm |
| Warm white form cards | Dark surfaces and visible gray input outlines | Keep fields distinguishable on a dark page |
| Browser chrome and favicon in old colors | Matching near-black chrome and neutral mark | Avoid a mismatched first paint |

Secondary copy uses `#b0b0b0`, brighter than the reference's muted ink to retain readability in dense financial forms. Status meaning remains explicit in labels and symbols, not dependent on accent color. Existing inputs retain outlines even though the reference prefers borderless surfaces.

Print output retains a light palette. No auth, provider or financial calculation changes are part of this update.
